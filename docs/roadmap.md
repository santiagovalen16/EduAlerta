# Roadmap MVP

## Fase 0 - Fundacion

- Monorepo.
- Next.js app shell.
- NestJS API.
- Prisma + PostgreSQL.
- Docker Compose.
- Swagger.

## Fase 1 - Seguridad

- Login.
- JWT access + refresh.
- bcrypt.
- RBAC por permisos.
- Auditoria base.

## Fase 2 - Dominio educativo

- Municipios.
- Instituciones.
- Estudiantes.
- Acudientes.
- Docentes y directivos.

## Fase 3 - Alertas

- Registro docente.
- Estados de alerta.
- Historial por estudiante.
- Validaciones robustas.

## Fase 4 - Dashboards

- Dashboard docente.
- Dashboard directivo.
- Dashboard territorial.
- Graficas y mapas.

## Fase 5 - Offline parcial

- Cola local de alertas.
- Sincronizacion.
- Indicador de conectividad.

## Fase 6 - Hardening

- Tests.
- Rate limiting.
- Logs estructurados.
- Exportaciones CSV.
- Nginx + TLS.
